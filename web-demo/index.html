notelight WebAssembly demo

The Rust search core, compiled to WebAssembly. Index a folder of your notes, or open the sample: indexing, embedding with bge-small and search all run in this page, and nothing is uploaded.

Your notes

Your files never leave this browser. They are read, chunked, embedded and stored on this device, in storage private to this site. The only network request is the one-time download of the bge-small model from Hugging Face, checked by SHA-256.

Reads .md, .markdown, .txt and the text of .pdf files (with pdf.js, loaded only for folders with PDFs), skipping hidden and build folders and whatever a .notelightignore lists, as the CLI does; DOCX is skipped for now. PDF results show their pages beside the lines. Updating an index embeds only the chunks that changed. Without semantic search the index is keywords only and the model is not needed.

      Or open an index

      The sample is this repository's docs/, indexed with the default embedder. The first hybrid search downloads bge-small (127 MiB) once; it is checked by SHA-256 and kept in this browser. To open one the CLI built, pick the index folder notelight status prints (or one gen-NNNNNN folder inside it).
